# USER PROFILE

Route

/dashboard/profile

---

# Purpose

The User Profile serves as the personal travel hub of the user. It stores profile information, travel preferences, achievements, saved destinations, and account activity while enabling a personalized experience across the ATLAS platform.

The profile should feel like a travel passport rather than a standard account page.

# Summary

The Profile & Settings module transforms the user account into a personalized travel portfolio while providing complete control over preferences, security, accessibility, and application customization. This module reinforces personalization, one of the core strengths of ATLAS.
